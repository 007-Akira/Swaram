# Changelog

## 0.1.0-rc.1 — 2026-07-26

Initial release candidate of the public Swaram software engine:

- expiring private sessions, uploads, Malayalam TXT/LRC/SRT parsing, ownership,
  signed range playback, retention, and explicit deletion;
- leased PostgreSQL worker with bounded FFmpeg normalization, pretrained
  HTDemucs separation, pYIN reference/timing analysis, retries, and cleanup;
- browser microphone lifecycle, YIN pitch detection, leakage/latency
  calibration, monotonic practice clock, windowed Canvas graph, lyrics, loops,
  playback speed/modes, scoring, feedback, and private reports;
- security hardening, non-root deployment artifacts, production validation,
  structured privacy-safe operations, automated browser/axe coverage, and
  generated-signal evaluation.

Known release-candidate limitations are tracked in `RELEASE_CHECKLIST.md`.
