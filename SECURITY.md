# Security policy

Please report vulnerabilities through GitHub's private vulnerability reporting
for this repository. Include affected commit/version, impact, reproduction
steps using generated or synthetic data, and a suggested mitigation if known.
Do not include real uploads, lyrics, session tokens, signed URLs, credentials,
or personal data.

If private vulnerability reporting is unavailable, contact the repository
owner privately to request a secure reporting channel without disclosing the
vulnerability details publicly. Do not open a public issue for an unpatched
security or privacy flaw.

The maintainers should acknowledge a report, assess severity, coordinate a
fix, rotate exposed secrets if applicable, and publish a concise advisory after
users can update. Supported security fixes currently target the latest `main`
release candidate; no long-term-support branch is declared.
